# Simple-web-scraper
Scrapes web pages and extracts clean text without heavy dependencies. Better than bloated scrapers: skips HTML junk, scripts, and extra whitespace, outputting ready-to-use data. Quick Start: pip install pydantic &amp; run python main.py.
